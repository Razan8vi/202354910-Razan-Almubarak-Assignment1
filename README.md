# Razan's Personal Portfolio - Assignment 1

## Project Description

This is a simple, responsive personal portfolio web application built as the
foundation for a professional portfolio website. It was created for **SWE 363
- Assignment 1: Foundation & AI Integration**.

The site includes three main sections:

- **About Me** - a short introduction and tagline.
- **Projects** - two sample projects, each with a title, description, and image.
- **Contact** - a simple contact form (Name, Email, Message). No backend is
  connected; the form is for front-end practice only.

The layout is built with plain HTML and CSS (Flexbox and the box model) and
includes one JavaScript feature: a greeting message that changes automatically
based on the time of day the visitor opens the page.

## Setup Instructions (Run Locally)

No installation or build tools are required - this is a static HTML/CSS/JS site.

1. Download or clone this repository:
   ```
   git clone https://github.com/<your-username>/studentID-razan-lastname.git
   ```
2. Open the project folder.
3. Open `index.html` directly in any modern web browser (double-click the
   file, or right-click → "Open with" → your browser).
4. That's it - no server or dependencies are needed to view the site.

## AI Use Summary

GitHub Copilot was used during development to speed up writing repetitive
HTML/CSS structure and to get suggestions while debugging small issues. All
AI-generated suggestions were reviewed, tested, and adjusted before being
kept in the final code. Full details, including benefits, challenges, and
what was learned, are documented in [`docs/ai-usage-report.md`](docs/ai-usage-report.md).
